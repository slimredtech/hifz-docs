# Cities for prayer-time reminders

`assets/data/cities.json` (3,085 places) and `assets/data/countries.json` (242 countries) are
generated by `scripts/build-cities.js`. Never edit them by hand.

## Contents

- **Hand-named (91):** the 58 Algerian wilaya seats and 33 major Arab cities, in
  `scripts/sources/cities/curated.json` (names written for the app, coordinates from GeoNames).
  Their ids (`dz-16`, `rabat`...) are stable and stored in users' settings.
- **Worldwide (2,994):** every national capital and every city of 200,000+ people, with ids
  `gn-<geonameId>`. Names in Arabic, French and English come from GeoNames' language-tagged
  alternate names (preferred first). 1,464 of them (mostly smaller cities in Asia) have no Arabic
  name in GeoNames and show their English name in the Arabic interface.
- **Left out:** places beyond 70° latitude (prayer times are undefined there for weeks; custom
  coordinates still work) and GeoNames' "Jerusalem, Israel" entry (the hand-named "Al-Quds,
  Palestine" covers it).

## Source

GeoNames (<https://www.geonames.org>), Creative Commons Attribution 4.0: `cities1000.txt`,
`countryInfo.txt` and `alternateNamesV2.txt`, downloaded 2026-10-15.

## Regenerating

```bash
mkdir -p /tmp/geonames && cd /tmp/geonames
curl -O https://download.geonames.org/export/dump/cities1000.zip
curl -O https://download.geonames.org/export/dump/alternateNamesV2.zip   # ~200 MB
curl -O https://download.geonames.org/export/dump/countryInfo.txt
unzip cities1000.zip && unzip alternateNamesV2.zip alternateNamesV2.txt
cd - && node scripts/build-cities.js /tmp/geonames
```

Then update the download date above and run `npm run check`.
