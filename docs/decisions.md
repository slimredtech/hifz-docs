## Proposed during M2, awaiting review

Where PLAN.md section 5 leaves room for interpretation. All live in `src/domain/`.

| Topic                 | Choice                                                                                                                                                                                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ladder (1, then 3)    | A "good" from a 1-day interval always goes to 3 days, after memorizing **and after a lapse**. Without it a page with ease below 1.5 stays at round(1 × ease) = 1 day forever.                                                                                            |
| Recent lapse          | "Lapses recently increased" = the page's latest rating was Forgot. It shows red until reviewed again. Needs a `lastRating` column in M3 (also added to the domain `PageProgress`).                                                                                       |
| Strength precedence   | Needs review > fading > fresh > solid/ok. A fresh page that is overdue shows as fading.                                                                                                                                                                                  |
| Juz 30 backward order | Surahs from An-Nas back to Al-Fatiha, each surah read forward page by page; a page shared by two surahs is learned with the later surah (reached first). Custom start page goes forward and wraps to page 1.                                                             |
| Half-page targets     | Default new target is **8 lines** (0.5 page = 7.5 lines, rounded up). The new section shows ceil(lines / 15) pages; the line target is shown as text.                                                                                                                    |
| Caps                  | Sabqi capped by a **recent limit, default 10** (PLAN gives no default); Manzil capped by the revision target (default 5). Due pages beyond the caps carry over; the backlog banner shows how many and an estimate of days to catch up.                                   |
| Plan stability        | Pages memorized or reviewed today stay in the plan as done and count toward the caps, so the plan doesn't grow while you work through it. An off-plan review from the map counts as done.                                                                                |
| Day complete          | Minimum goal: every Sabqi page + at least one Manzil page. If nothing is due, the new page is required. An empty plan counts as complete. Alternative goal: the full plan.                                                                                               |
| Streak and grace      | Settled one day at a time into persisted state. A missed day uses a grace day only while a streak is running; it keeps the streak but doesn't add to it. Grace spent stays spent, so Premium ending never breaks a streak already earned. Today never breaks the streak. |

## M3 choices (confirmed 2026-10-15)

| Topic                  | Choice                                                                                                                                                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Onboarding spread      | Pages already known get first reviews spread over a window of ceil(pages / revision target) days, at least 14 and at most 60 (PLAN.md 6.1), dealt round-robin after a day-seeded shuffle, starting tomorrow. With the whole mushaf and target 5 that is ~10 a day, so the backlog carry-over absorbs the excess. **Confirmed: keep as is.** |
| Known pages are Manzil | Their real memorization date is unknown, so `memorizedOn` is set to 31 days ago: they show as old revision, not "fresh" or Sabqi.                                                                                                                                                                                                           |
| Rows are never deleted | Resetting a page writes a not-memorized row so the reset syncs (last-write-wins, M8). Undo deletes the review-log entry it created.                                                                                                                                                                                                         |
| Settings ranges        | New lines 1-30, Sabqi limit 1-50, revision target 1-100. Invalid or damaged stored values fall back to defaults field by field instead of crashing.                                                                                                                                                                                         |
| Drizzle version        | Stable `drizzle-orm` 0.45 / `drizzle-kit` 0.31 rather than the 1.0 release candidate the Drizzle guide now suggests.                                                                                                                                                                                                                        |

## M7 choices (confirmed 2026-10-15)

| Topic             | Choice                                                                                                                                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Without a project | The app builds and runs without Supabase settings and simply does not sync. Adding `.env.local` and rebuilding is the only step left (runbook).                                |
| Grants            | Default privileges revoked: every table must grant explicitly (fails closed). Signed-out (`anon`) requests can only call `ping()`.                                             |
| Teacher access    | Read-only, only while a link is `active`; either side can revoke. Accepting an invite (pending → active) will be a rate-limited function in M9; clients cannot activate links. |
| Activity upload   | The last 7 days of `daily_activity` (days used + review counts) are upserted a few seconds after changes, so offline days catch up.                                            |
| Server checks     | Page 1-604, ease 1.3-3.0, interval ≤ 120, note ≤ 140 chars, settings JSON ≤ 16 KB, display name ≤ 40 chars; `updated_at` always set by the server.                             |
| Backups           | The free plan has no backups. Options in the runbook; **decision needed before launch**.                                                                                       |
| Anonymous abuse   | Default limit of 30 anonymous sign-ins per hour per IP. A CAPTCHA would add a third-party service, so not now; revisit if abuse appears.                                       |

## Proposed during M8, awaiting review

| Topic                 | Choice                                                                                                                                                                                                                                                                                                                                                                                  |

| Sync timing           | On open, foreground, 3 s after changes, day change, network back, daily background task; failures retry after 2 s, 4 s, 8 s... up to 5 min.                                                                                                                                                                                                                                             |
| Backup file           | JSON, versioned (`hifz-planner-backup`, v1), free. Import validates everything and asks **Replace** or **Combine**.                                                                                                                                                                                                                                                                     |
| Deleting              | One button deletes the server account (Edge Function) and everything on the phone, then the app restarts at onboarding. Offline: nothing is deleted, the user is told to retry. | Sign out              | Not offered in v1: signing out would leave the phone with someone's data and no account. | Backup card           | Shown on Today after the first review or memorization while progress is on the phone only; "Not now" hides it on this phone for good; Settings always offers the same.                                                                                                                                                                                                                  |
